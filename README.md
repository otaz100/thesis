# ORFE Senior Thesis

Work toward my senior thesis on learning to play games from footage: pretraining an agent on gameplay recordings that have
no recorded actions, then fine-tuning it online in as few episodes as possible.

| Project | Summary |
|---|---|
| [lapo-double-pendulum](lapo-double-pendulum/) | LAPO (Learning to Act without Actions) rebuilt from scratch on the MuJoCo inverted double pendulum, with a CartPole check |
